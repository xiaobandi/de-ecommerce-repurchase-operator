# 复购报表 · 架构与流程图

## 本技能的四层结构

```mermaid
flowchart TB
  U["使用层：私域复购运营 的使用者"]
  T["触发层：复购报表"]
  X["执行层：5 个步骤"]
  O["产出层：月报"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 有老客盘（累计订单 1000+）的腰部卖家；员工定位：私域运营专员·小复 ｜ 一人店用得起的私域，不碰有赞/微盟的重资产玩法 |
| 触发层 | 关键词 / 显式点名「复购报表」；触发方式：用户提出需求 |
| 执行层 | **接收输入**：确认拿到的是「订单表」，先做完整性检查。 → **复购指标计算与解读**：按该定义执行，并把用到的输入项显式写进产出。 → **交叉校验**：把本步结论与上一步结论对一遍，出现矛盾先解决矛盾再往下走。 → **落盘产出**：按「输出契约」四要素定稿，缺数据的写 `<待填>`。 → **回指自检**：逐个数字回指输入来源，回指不上的删掉。 |
| 产出层 | 月报 |
