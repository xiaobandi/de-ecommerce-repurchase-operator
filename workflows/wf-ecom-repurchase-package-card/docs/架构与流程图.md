## 本工作流的四层结构

```mermaid
flowchart TB
  U["使用层：私域复购运营 的使用者"]
  T["触发层：包裹卡/售后卡文案"]
```

|---|---|
| 使用层 | 有老客盘（累计订单 1000+）的腰部卖家；员工定位：私域运营专员·小复 ｜ 一人店用得起的私域，不碰有赞/微盟的重资产玩法 |
| 触发层 | 关键词 / 显式点名「包裹卡/售后卡文案」；触发方式：人工 |
| 执行层 | 商品/人群 → 卡片文案 → 合规检查 |
| 产出层 | 合规检查 |
