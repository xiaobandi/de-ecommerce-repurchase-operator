# 03 · 场景与价值

## 谁在用

有老客盘（累计订单 1000+）的腰部卖家

## 三个典型场景

### 场景 A：包裹卡/售后卡文案
- **触发**：人工
- **之前**：人工从头做一遍，每次口径不一、结果不可比
- **之后**：商品/人群→卡片文案→合规检查
- **收益**：随包裹零成本触达，最快见效

### 场景 B：订单老客分层（RFM）
- **触发**：定时（每周）
- **之后**：订单导出→RFM 计算→分层名单
- **收益**：月省数据分析 8h≈¥240

### 场景 C：复购周期预测与触达文案
- **触发**：定时（每周）
- **之后**：消耗周期→到期名单→触达文案
- **收益**：耗材类复购提醒直接出单

## 价值构成

| 维度 | 说明 |
|---|---|
| 省时间 | 对标有赞/微盟数千到数万报价（据R3调研）；月省 10h≈¥300 |
| 提一致性 | 同一能力固化成技能，口径不再因人而异 |
| 降风险 | 业务红线写死在提示词里，越界即停 |
| 可审计 | 每个数字可回指输入，产出可追溯 |

## 与人工的边界

本员工**不替代决策**。它负责把重复劳动做成清单与初稿，
把决策点（要不要发、要不要改价、要不要道歉）留给人。
